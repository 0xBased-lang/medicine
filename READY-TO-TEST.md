## 🛠️ Troubleshooting

### Workflow won't execute
```bash
# Check Ollama is running
ollama list
ollama run llama3.2:3b "test"

# Check n8n logs
docker logs n8n_medicine

# Restart if needed
docker-compose restart
```

### Discovery finds no books
- Archive.org API might be rate-limited
- Try again in 5 minutes
- Check: `curl https://archive.org/advancedsearch.php`

### Ollama is slow
- First run warms up GPU cache
- Subsequent runs are faster
- Check Activity Monitor (Mac)
- Be patient! ☕

### Script generation errors
```bash
# Verify Ollama
curl http://localhost:11434/api/tags

# Check model
ollama list
# Should show: llama3.2:3b

# View n8n logs
docker logs n8n_medicine
```
